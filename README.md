# Ancy Albert — Technical Writing Portfolio

Files:
- `index.html` — portfolio homepage with one completed article and six planned article titles
- `the-environment-is-the-test.html` — completed independent AI technical explainer
- `styles.css` — responsive editorial styling

Preview: open `index.html` in a browser, keeping all files in the same folder.

Publish:
1. Create a GitHub repository named `ancy-technical-writing-portfolio`.
2. Upload all files to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Use the published URL shown there.

Before sharing:
- Add a professional email and LinkedIn URL.
- Add only verified professional achievements and samples you are allowed to share.
- Planned article cards are explicitly labelled as not yet written.
- Keep the independent-work disclosure on the article.
